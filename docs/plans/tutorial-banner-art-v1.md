The blog layout mounts one shared GitHub exit-intent dialog for all blog routes. It activates only on desktop pointer exit through the upper page edge, after 30 seconds and 250 px of scroll. It stays closed on mobile, during initial reading and after it has been shown in the session. Escape, close and backdrop dismissal remain available. Navigating between blog articles does not create duplicate dialog instances.
