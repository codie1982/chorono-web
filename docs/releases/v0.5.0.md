# Chorono v0.5.0 release candidate — Mesh2D, physics baking and fracture

**Status:** Release candidate. The GitHub v0.5.0 release is still a draft; there is no public tag or download yet. The scope and checks below describe the candidate at [`3efb73cd`](https://github.com/codie1982/chorono-editor/commit/3efb73cde632b6b63202020e345e7202c22f1eb4).

Chorono v0.5.0 prepares editable 2D meshes, reviewable physics bakes, deterministic fracture and built-in image rendering. You can preview the result in the editor and keep working in the same portable project.

## Mesh2D

- Create a structured grid or generate a mesh from a closed shape or spline, then inspect its topology in the viewport.
- Place and crop textures, pin vertices and play baked deformation clips. Portable projects preserve source, mesh and clip data.

## Physics and fracture

- Review track and rigid-body bakes in **Jobs & Bake** before applying them. Apply is one Undo step; ownership checks protect user-edited tracks during replacement or clearing.
- Break supported sources into deterministic Voronoi fragments. Complex regions support concave outlines and holes, while textured Mesh2D fragments retain source UVs.
- Author breakable bonds and bake secondary fracture events. Inspect event timing, fragment lineage and collider geometry in the editor or through MCP.

## Render

**Export → Render…** produces a PNG or PNG sequence ZIP with the built-in renderer. When the separate local Chorono Render service is running, you can send frames to 2D Video Studio for finishing. Video export through that bridge uses PNG frames and does not include an audio track.

## Validation and current limits

The [candidate validation report](https://github.com/codie1982/chorono-editor/blob/3efb73cde632b6b63202020e345e7202c22f1eb4/docs/releases/v0.5.0-validation.md) records 3,309 passing unit tests, CLI and MCP builds, a production build, a recursive fracture bake and a PNG portable round trip. Full smoke and B1–B6 regression, rigid cancellation, PNG sequence, external renderer handoff and the broader portable fixture matrix remain open. Compatibility with separately versioned Player, runtime and SDK packages is unverified.
